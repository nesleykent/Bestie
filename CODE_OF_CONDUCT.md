# Code of Conduct

## Our standard

This repository welcomes respectful collaboration from Tibia players, data contributors, designers, and developers. Participate with patience, assume good faith while evidence is incomplete, and critique ideas and implementations rather than people.

Helpful participation includes:

- giving clear, reproducible feedback;
- respecting different experience levels, languages, identities, and play styles;
- citing sources when correcting Tibia rules or bundled data;
- protecting personal information in logs, screenshots, and issue reports;
- accepting maintainer decisions about scope without harassment.

Harassment, discrimination, threats, sexualized attention, deliberate humiliation, doxxing, spam, and sustained disruptive behavior are not acceptable.

## Scope

These expectations apply in repository issues, pull requests, discussions, reviews, and other public spaces used to represent this project.

## Enforcement

Maintainers may edit or remove content, close participation, or block contributors when necessary to keep the project safe and productive. Enforcement decisions should be proportionate to the behavior and may account for repeated patterns.

To report a conduct concern privately, contact the repository owner through the contact method listed on the [maintainer's GitHub profile](https://github.com/nesleykent). If no private contact method is available, open an issue requesting private contact without including sensitive details.
