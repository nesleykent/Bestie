# Support

Bestie is an unofficial, community-maintained Tibia tool. It cannot access a Tibia account, recover in-game progress, or provide CipSoft account support.

## Before opening an issue

1. Hard-reload the application with `Cmd+Shift+R` on macOS or `Ctrl+Shift+R` elsewhere.
2. Confirm the Hunt Analyzer text matches the accepted format in the [README](README.md#accepted-hunt-analyzer-shape).
3. Check the relevant feature description and [current boundaries](README.md#current-boundaries).
4. Search [existing issues](https://github.com/nesleykent/Bestie/issues) for the same behavior.

## Where to ask

- Use the [bug report](https://github.com/nesleykent/Bestie/issues/new?template=bug_report.md) for broken behavior, incorrect calculations, bad bundled data, or import problems.
- Use the [feature request](https://github.com/nesleykent/Bestie/issues/new?template=feature_request.md) for new trackers, planning workflows, or repository improvements.
- Use [GitHub Security Advisories](https://github.com/nesleykent/Bestie/security/advisories/new) for vulnerabilities that should not be public.
- Contact [Tibia support](https://www.tibia.com/support/) for account, payment, game-client, or enforcement matters.

## Privacy

Issue reports are public. Remove character names, private notes, and unrelated Hunt Analyzer content before attaching examples or screenshots. A minimal synthetic example is usually enough to reproduce parser or calculation problems.

The application stores progress in the current browser profile. Clearing site data or using another browser profile can make that local data unavailable.
